# Telegram News Bot 📰

An ad-friendly, privacy-focused Telegram bot providing educational content on crypto, news, sports, and finance. No external API keys required.

## Features

✅ **4 Main Categories:** Crypto, News, Sports, Finance
✅ **Ad-Friendly:** No data collection, no tracking
✅ **No API Keys:** Runs entirely on internal content
✅ **Educational Focus:** Informational content only
✅ **Privacy First:** No user data stored
✅ **24/7 Availability:** Deployed on Railway

## Quick Deploy to Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/deploy)

Or manually:

1. Clone this repo
2. Install dependencies: `npm install`
3. Create `.env` with your `BOT_TOKEN`
4. Deploy to Railway

## Commands

- `/start` - Welcome menu
- `/crypto` - Cryptocurrency education
- `/news` - Global news summaries  
- `/sports` - Sports information
- `/finance` - Finance education

## Bot Token

Get your bot token from [@BotFather](https://t.me/BotFather) on Telegram.

## Why This Bot?

- **Telegram Ads Compliant:** No imperative verbs, no "you" addressing, no unrealistic claims
- **Educational Value:** Curated content on topics people care about
- **No External Dependencies:** Everything runs on built-in content
- **Community Building:** Focuses on adding value to telegram channels
